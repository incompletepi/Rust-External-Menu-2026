## Troubleshooting

### Menu does not open

- verify the menu hotkey;
- restart the interface;
- check the current project version;
- reset the profile if the interface configuration became invalid.

### Settings are not saved

- verify folder write permissions;
- create a fresh configuration profile;
- reset the affected interface section;
- avoid editing profile files while the project is running.

### Overlay layout is incorrect

- reset panel positions;
- reload the default profile;
- verify display scaling;
- test another interface preset.

### Information panels look outdated after a Rust update

Rust updates can affect compatibility. Use the most recent project build and reset outdated profiles when needed.
